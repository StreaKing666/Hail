## Осталось и ограничения

1. Ручные операции из PagerFragment/ApiActivity частично синхронны. При медленном root возможна блокировка UI; JVM-проверки не измеряют ANR на Android.
2. FreezeController читает состояние сразу после команды один раз. Недоступный пакет даёт UNVERIFIED; задержка обновления PackageManager и доступ к privateFlags зависят от устройства. Эти сценарии не объявляются исправленными.
3. Счётчик .13 показывает только подтверждённые успехи. Значение 0 возможно и при отсутствии новых действий, и при неподтверждённых командах; это не гарантия успешной заморозки всех пакетов. Причины созданных операций остаются в журнале.
4. Экспортированный ApiActivity — существующий интерфейс автоматизации без отдельного разрешения вызывающего приложения. Он позволяет управлять выбранными приложениями/профилями; API не расширялся модулем. Системные службы и provider защищены соответствующими разрешениями.
5. apksigner предупреждает о служебных META-INF-записях вне защиты v1; подписанный контент проверен v2. AGP записал NO_VALID_GIT_FOUND в служебные VCS-метаданные. ## Граница прав и замены

Пакет совпадает с upstream Hail, сертификат Enhanced другой. Установщик не переносит подпись upstream, не отключает её проверку и не удаляет установленный /data/app APK. Обычное обновление разными сертификатами несовместимо; поведение имеющихся на устройстве патчей подписи здесь не проверено. /data/app-обновление может остаться активным вместо APK модуля; Action должен проверять именно активный APK.

Android 16 определяет MANAGE_APP_OPS_MODES как signature|installer|verifier|role, без privileged. Allowlist не делает это право выданным автоматически. FORCE_STOP_PACKAGES и CHANGE_COMPONENT_ENABLED_STATE имеют privileged-флаг. Фактические granted=true нужно смотреть после перезагрузки.
