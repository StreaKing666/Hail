# Enhanced .13: результат массовой заморозки

Изменение относительно .12: уведомление массовой заморозки/разморозки в приложении и через ярлыки всегда содержит число подтверждённых операций. При отсутствии новых подтверждённых операций — 0; дробь и название единственного приложения в этом уведомлении больше не используются.

Причина некорректного сообщения: AppManager.setListFrozen возвращал null, когда список был непустым, но подтверждённых результатов было 0. ApiActivity превращал null в окно «Разрешение отклонено», PagerFragment — в такое же всплывающее сообщение. Сам по себе ноль подтверждённых операций не является доказательством отсутствия полномочий. Пустой список уже возвращал 0; скриншот пользователя также показывает неподтверждённые операции по оставшимся пакетам.

Исправление относится к отображению результата, а не к получению root или изменению способа заморозки. Успех засчитывается только при outcome=SUCCESS и stateVerified=true. Все созданные записи операций, включая FAILED и UNVERIFIED, сохраняются в существующем журнале. Число 0 не означает, что все запрошенные команды успешно выполнены. Для выяснения причин неподтверждённых операций используется журнал заморозки.

Проверки и сборка фиксируются отдельно в сопроводительном отчёте. Проверка на устройстве недоступна. Минимальные сценарии приёмки: заморозить размороженные приложения; повторить при уже замороженных; проверить частичный результат, разморозку, ярлык тега и ярлык массовой заморозки.

Данные, формат резервных копий, подпись, packageName и root-команды не изменены. Для обновления .12 следует выбрать тот же вариант пакета. Версия приложения: 1.11.0-enhanced.13, versionCode 111013.
