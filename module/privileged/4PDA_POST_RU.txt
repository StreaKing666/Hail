[b]Hail Enhanced Privileged — модуль 1.0.0 / Enhanced .11[/b]

[spoiler=Что делает]
Размещает подписанный Enhanced .11 в system/priv-app и добавляет XML системных разрешений. Сам APK не изменён. Это тестовая сборка.
Основан на Hail Universal Privileged 2.1.0 (+SWAG+); оригинальное приложение — aistra0528 и участники.
[/spoiler]
[spoiler=Установка]
1. Экспортируйте данные Enhanced.
2. Для KernelSU/ReSukiSU нужен один работающий метамодуль монтирования system. Если NoMount уже работает, второй не нужен.
3. Установите ZIP через root-менеджер и перезагрузитесь. Не через Recovery.
4. Выполните Action: проверьте системный/привилегированный статус и фактические разрешения.
5. В Hail выберите «Системное приложение - Отключить» либо «Системное приложение - Принудительно остановить». Проверьте на некритичном приложении.
[/spoiler]
[spoiler=Совместимость и ограничения]
Отдельные ID модуля, пакет, каталог APK и XML: оригинальный Hail не заменяется. Противоположные правила двух Hail могут мешать друг другу. Ссылки hail:// могут открывать выбор приложения. Автоматического переноса данных нет.
Для обновления установленного Enhanced нужна совпадающая подпись. Инсталлятор не удаляет прежнюю установку. Перед удалением модуля разморозьте приложения и сохраните данные.
Нет WebUI. Action — только диагностика. Аппаратная проверка этого модуля ещё не проведена. Ошибки и ограничения .11 сохраняются.
[/spoiler]
