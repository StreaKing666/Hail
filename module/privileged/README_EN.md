# Hail Enhanced Privileged / Enhanced .12
Unofficial systemless wrapper derived from Hail Universal Privileged (+SWAG+).
The signed com.aistra.hail.enhanced APK is embedded byte-for-byte without re-signing.
Use Magisk or KernelSU/ReSukiSU with one working system-mount metamodule.
Install with the root manager, reboot and inspect Action output for actual permissions.
The original Hail package/module is separate. This wrapper does not bypass APK signatures.
Back up externally before installation/removal. Device acceptance remains NOT_RUN.
See README_RU.md, tests, and the application reliability report for details.
