# Hail Enhanced Privileged 1.0.0
Experimental systemless packaging of the unchanged signed Enhanced .11 APK.
Based on +SWAG+'s Hail Universal Privileged 2.1.0. Original Hail: aistra0528 and contributors.
Separate ID Hail-Enhanced-PrivApp, package com.aistra.hail.enhanced and APK/XML paths.
Install in Magisk/KernelSU/ReSukiSU manager and reboot; KernelSU requires a working system-mount metamodule. Recovery unsupported.
Run read-only Action, inspect SYSTEM/PRIVILEGED and actual grants; select System App Disable or Force Stop.
Export data before installation/removal; thaw apps before removal. No automatic data deletion or migration.
Original Hail can coexist, but opposing automation and shared hail:// handlers may interact.
No device validation performed. This packaging does not fix .11 app bugs.
See README_RU.md, APP_AUDIT.md, NOTICE and LICENSE.
